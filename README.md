# PipeMark Studio v5

배관 마커, 안전표지, 설비/점검, LOTO, 물류, 명판 등을 **기본값 선택만으로 빠르게 만들고**, 예외 상황에서는 캔버스 위의 글자와 SVG를 직접 움직여 편집하는 GitHub Pages용 정적 웹앱입니다.

## 이번 v5의 핵심

- **배관 규격 연동 크기**: 20A와 100A를 같은 크기로 취급하지 않습니다. 외경/단면 크기가 커지면 라벨 높이, 폭, 글자 크기가 함께 증가합니다.
- **부착 범위**: 평면/한 면, 반둘레, 3/4 둘레, 한바퀴 360°를 선택하면 원주 또는 둘레를 이용해 세로 길이를 계산합니다.
- **두 줄 정보형**: 큰 문구 + 작은 보조문구/규격(`SGP 20A · Ø27.2 mm`)을 기본으로 사용할 수 있습니다.
- **1줄/2줄/자동**: 긴 문구는 자동 또는 수동으로 2줄 배치할 수 있습니다.
- **실제 디자인 선택**: 배관 8종, 안전/산업표지 14종 이상의 디자인을 썸네일로 비교한 뒤 선택합니다.
- **화면 디자인 6종**: Studio / Blueprint / Workshop / Soft / Mono / Dark Control.
- **직접 편집**: 글자/SVG를 클릭 후 드래그 이동, 모서리 핸들 크기조절, 위 핸들 회전. 글자는 더블클릭하면 캔버스에서 바로 수정됩니다.
- **객체 편집기**: 글자 크기, 굵기, 글꼴, 색, 정렬, 자간, 줄간격과 SVG 아이콘/색을 조절합니다. 좌표 숫자는 `정밀 수치 조정`을 열었을 때만 보입니다.
- **SVG 추가**: 외부 SVG 파일을 불러오거나 캔버스에 드롭하고, 바로 이동/크기/회전을 편집합니다.
- **산업 라벨 라이브러리**: 배관·유체, 위험·경고, 금지·제한, 보호구·지시, 비상·소방, LOTO·점검, 전기, 기계·설비, 화학, 물류, 구역·바닥, 창고·적재, 명판·자산, 사용자 라벨.
- **A4/A3 자동 배치**: 실제 mm 크기로 라벨을 배치하고, 세로/가로 중 페이지 효율이 좋은 방향을 자동 선택합니다.
- **Local-first**: 별도 DB 없이 브라우저 LocalStorage에 자동 저장하고 JSON으로 PC 백업/복원합니다.

> 내장 규격/크기/색상은 편집 시작용 참고값입니다. 법정표지, 발주처 기준, 사업장 안전규정 및 실제 제조사 치수가 있다면 그 기준을 우선해 주세요.

## 빠른 사용법

1. `카테고리 → 템플릿`을 고릅니다.
2. 배관이면 `제품군 → 규격 → 유체/용도 → 크기 기준 → 부착 범위`를 고릅니다.
3. `자동 / 1줄 / 2줄`과 문구를 확인합니다.
4. 화면에 보이는 디자인 카드에서 원하는 모양을 고릅니다.
5. 기본값으로 충분하면 바로 `출력 목록에 추가`합니다.
6. 공간이 좁거나 문구/아이콘 위치를 바꿔야 할 때만 `화면에서 직접 편집`을 켭니다.
7. `출력 용지`에서 A4/A3 자동 배치를 확인하고 인쇄/PDF로 저장합니다.

## 직접 편집

- 객체 클릭: 선택
- 객체 드래그: 이동
- 오른쪽 아래 원형 핸들: 크기조절
- 위쪽 원형 핸들: 회전
- 글자 더블클릭: 캔버스에서 바로 문구 수정
- 오른쪽 `선택 객체` 탭: 글자 크기/굵기/글꼴/색/정렬/자간/줄간격 변경
- SVG 파일 드롭 또는 `SVG 파일` 버튼: 사용자 아이콘 추가
- 가운데 스냅: 객체가 캔버스 중앙에 가까워지면 가이드 표시

## 배관 크기 로직

`배관 규격 연동형`은 **법정 규격을 주장하는 값이 아니라 A4 출력과 식별성 사이의 실용 프리셋**입니다. 외경 또는 각관의 대표 치수가 커질수록 라벨 크기를 단계 없이 자연스럽게 확대합니다. `표준 참고형`은 긴 색상대와 큰 식별성을 우선하며, `직접 크기`에서는 현장 기준을 그대로 입력할 수 있습니다.

원형 배관에서 반둘레/3/4/360°를 선택하면 선택 규격의 외경으로 원주를 계산해 라벨 세로 길이에 반영합니다.

## 저장

- 현재 상태: LocalStorage 자동 저장
- 현장 저장: 브라우저 안에 여러 현장 저장
- JSON ↓ / ↑: 전체 프로젝트 PC 백업/복원
- 사용자 SVG도 프로젝트 백업에 포함

## GitHub Pages 게시

Windows에서는 프로젝트 폴더의 `github-bootstrap.cmd`를 실행합니다.

게시 스크립트가 다음을 처리합니다.

1. Git / GitHub CLI 확인
2. GitHub 로그인 확인
3. Repository 생성 또는 기존 Repository 연결
4. 기존 `origin`이 없으면 자동 추가
5. 기존 원격 `main` 이력이 있으면 안전하게 연결
6. 사이트 URL 메타데이터 반영
7. Commit / Push
8. GitHub Pages + Actions 설정
9. Repository **About(Edit repository details)** 자동 설정
   - Description
   - Website (GitHub Pages URL)
   - Topics
10. Actions 배포 상태 확인 및 최종 URL 표시

작업 로그는 `github-bootstrap.log`에 남고 실패해도 CMD 창이 바로 닫히지 않습니다.

Repository Social Preview용 이미지는 `assets/repository-social-preview.png`입니다. GitHub 웹사이트의 `Settings → General → Social preview`에서 한 번 등록하면 됩니다.
